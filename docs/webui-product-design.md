# FlowLens 1.2 WebUI 产品化设计

FlowLens 的默认界面已经从单次爬虫控制台调整为网站用户优先的数据工具。用户主路径固定为：连接抖音账号、创建采集、跟踪任务、浏览结构化结果、播放本地媒体。原有多平台本机采集能力保留在“设置 → 本机高级工具”。

## 信息架构

桌面端采用固定侧边导航，分为工作台、数据、自动化和账号四组。移动端使用抽屉与“首页、任务、内容、账号”四项底部导航。管理员页面使用独立深色外壳，不出现在普通用户导航中。

路由使用 `HashRouter`，因此 FastAPI 静态文件服务无需为每个前端路径增加 SPA 回退：

```text
/#/                         工作台
/#/connect                  抖音账号
/#/crawl/new                三步采集向导
/#/tasks                    任务中心
/#/tasks/:runId             任务详情
/#/library                  内容库
/#/library/awemes/:awemeId  内容详情
/#/media                    媒体库
/#/schedules                定时计划
/#/settings                 设置与本机高级工具
/#/admin/*                  管理员后台
```

## 视觉基准

- 中文浅色版是基准，保留现有语言与主题开关。
- 页面使用冷灰背景、白色表面、深蓝灰文字和深青蓝主操作色。
- 基础圆角 8px，业务卡片 12px；间距采用 4、8、12、16、24、32。
- 核心按钮与移动操作目标最小 44px，焦点状态清晰可见。
- 状态同时使用文字、图标与语义颜色，不只依赖颜色传递信息。
- `prefers-reduced-motion` 下关闭非必要动画。

## 前后端契约

`GET /api/system/capabilities` 返回运行模式、当前角色和特性开关。远程模式下，普通请求头不能提升为管理员，必须同时经过受信代理认证。

`GET /api/dashboard/overview` 聚合账号、任务数、最近任务、内容统计、健康检查与磁盘摘要。远程模式依赖网站服务端注入的可信用户上下文，不接受请求体中的 `user_id`。

任务列表和详情返回可读名称、用户化状态、阶段统计、进度、预计剩余时间和 `allowed_actions`。前端只渲染服务端允许的任务操作。

本地内容库支持作品分页以及文案、作者、关键词/话题、时间、互动量、字幕、评论和下载状态筛选。JSONL/CSV 导出复用同一筛选条件。远程内容详情通过租户隔离接口组合作品、评论树、字幕、指标和媒体元数据。

## 关键状态

账号连接页覆盖未连接、二维码生成、已扫码、手机确认、成功、过期、执行设备离线、验证码和风控。二维码离开登录状态后立即从页面移除；页面文案不向普通用户暴露浏览器调试参数或本地路径。

任务中心将内部状态转换为排队中、正在采集、正在暂停、已暂停、等待登录、磁盘空间不足、部分完成、已完成、失败和已取消。每种状态只出现当前有效的操作。

内容详情包含文案与媒体、元数据和音乐、指标趋势、字幕时间轴以及按需展开的二级评论。媒体库只为已验证的正式视频提供播放，删除操作保留数据库记录。

## 验证命令

```shell
cd webui
npm ci
npm run lint
npm run build

cd ..
python -m pytest -q
```

浏览器回归至少覆盖 1280×桌面、390×844 移动端、浅色与深色、三步向导、状态操作、无数据状态和内容详情。真实远程扫码、验证码处理及 Range 播放仍需在启用远程模式、网站会话与在线 Worker 的验收环境中执行。
